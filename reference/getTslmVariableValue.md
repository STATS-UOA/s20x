# Look up a name used by a tslm formula

Look up a name used by a tslm formula

## Usage

``` r
getTslmVariableValue(name, data, envir)
```

## Arguments

- name:

  variable name.

- data:

  data frame or environment used to evaluate the model formula.

- envir:

  environment of the model formula.

## Value

The value of \`name\`, or \`NULL\` if it cannot be found.
