# Check whether a name refers to data

Check whether a name refers to data

## Usage

``` r
isTslmDataVariable(name, data, envir)
```

## Arguments

- name:

  variable name.

- data:

  data frame or environment used to evaluate the model formula.

- envir:

  environment of the model formula.

## Value

\`TRUE\` when \`name\` is a column of \`data\` or a vector of values.
