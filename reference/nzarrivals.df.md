# Monthly Arrivals to New Zealand

Monthly international passenger arrivals to New Zealand from January
1921 to February 2026. Missing monthly observations, if present in the
source series, are retained as rows with missing \`arrivals.count\`
values.

## Format

A data frame with monthly observations on 3 variables.

- year:

  Integer year.

- month:

  Factor month abbreviation with levels given by \`month.abb\`.

- arrivals.count:

  Integer number of international passenger arrivals.

## Source

Stats NZ Infoshare, table ITM049AA, Total passenger movements (monthly),
Arrivals, Actual Counts. Last updated 14 April 2026.
